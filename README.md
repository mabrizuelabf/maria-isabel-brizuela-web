# Sitio web — María Isabel Brizuela

Landing page estática (HTML/CSS/JS) con estética minimalista, cálida y profesional.

## Cómo verlo en tu computador

Opción simple:

- Abre `index.html` en tu navegador.

Opción recomendada (para que funcionen mejor algunas cosas del navegador):

```bash
cd "maria-isabel-brizuela-web"
python3 -m http.server 5173
```

Luego abre `http://localhost:5173`.

## Personalización rápida

En `index.html`:

- Cambia el **correo**: busca `hola@mariaisabelbrizuela.cl`
- Cambia el **WhatsApp**: busca `+56 9 0000 0000` y el enlace `wa.me/56900000000`
- Ajusta textos de **servicios** y **formación** según corresponda

En `styles.css`:

- Paleta (variables CSS) está al inicio, en `:root`
